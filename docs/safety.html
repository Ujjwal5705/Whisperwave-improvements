Questions before you start

Can the other person see my real name?

The proposed guest experience uses an alias. Whatever you write in a live conversation is visible to the other person.

Is this a place to get urgent help?

Whisper Wave is a conversation product. If you’re in immediate danger, contact your local emergency services.

Where can I report something that happened on the live site?

Use the live site’s reporting page. This redesign preview does not deliver reports. Open live reporting
